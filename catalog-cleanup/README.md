# Очистка выгрузки каталога

Самостоятельная демонстрация на вымышленных данных. Скрипт использует стандартную библиотеку Python.

Открой терминал в этой папке и выполни:

```powershell
python -B clean_catalog.py source.csv
python -B -m unittest -v
```

Первая команда запускает [скрипт](clean_catalog.py) на [исходной выгрузке](source.csv) и записывает рядом [каталог](catalog.csv) и [отчёт](review.csv). При повторном запуске эти два файла обновляются. Вторая команда запускает [тесты](test_clean_catalog.py) во временной папке. Они проверяют дубли, ошибочные цены, отсутствующие поля, конфликт цен и итоговые числа.

Формат входа — CSV в UTF-8 с заголовком `sku;name;price`. Артикулы приводятся к верхнему регистру и очищаются от пробелов по краям. Цены в рублях записываются с точкой и двумя знаками после неё. На входе поддерживаются точка или запятая, пробелы в качестве разделителя тысяч и необязательный знак ₽. Нулевые, отрицательные и нечисловые цены идут на проверку. При одинаковой цене сохраняется первая корректная запись артикула.

Если у артикула несколько разных корректно записанных цен, все его исходные записи идут в отчёт. В нём есть номер записи в CSV (заголовок считается первой записью), исходные значения, причина и список найденных цен. Например, у B-205 в записях 4 и 5 указаны 2490.00 и 2590.00. Уточни цену у владельца каталога, поправь исходную выгрузку и запусти скрипт повторно.

Фактический вывод на Python 3.15.2:

```text
processed=11 catalog=3 review=6 duplicates=2
Ran 4 tests
OK
```
